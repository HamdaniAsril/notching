# Musik (Now playing) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the three music widgets: Musik (2 columns), Musik strip, and Musik kecil (1 column). They read macOS Now Playing through an owner-approved `/usr/bin/perl` helper, and the controls play, pause and skip.

**Architecture:**
- **Helper.** A small Objective-C dylib is loaded by system perl. It streams JSON lines on stdout and takes commands on stdin.
- **Rust service.** A `media_service` keeps the helper alive while the `musik` package is on, and serves the new `media` capability.
- **Widget package.** A new package `modules/musik` draws the widgets in the Volt look.

**Tech Stack:** Rust (Tauri 2), Objective-C (clang, Foundation, private MediaRemote via dlopen), perl 5 DynaLoader, vanilla TS + vitest.

**Spec:** `docs/superpowers/specs/2026-11-03-musik-design.md`. Visual language: `docs/superpowers/specs/2026-11-02-gaya-volt-design.md` §3–§4. Spike proof: the controller's scratch test read title "PEMILIK NOMOR…", artist "Jon Wibu" and duration 2538 s from Arc via perl, and got `keys=0` from a plain binary.

## Global Constraints

- **The perl route only, owner-approved.** No other bypass, and no AppleScript fallback in this round.
- **One process.** At most one helper process at a time. It is killed when the package turns off and when the app exits; also tie its life to the app, e.g. the helper exits when stdin closes.
- **Restart backoff.** When the helper dies: 1, 2, 4 … 30 s. A bad JSON line is skipped, never a crash.
- **Data stays in memory.** Nothing is written to disk or sent over the network.
- **Artwork** is at most 128 px on the long side, as base64 PNG or JPEG.
- **Build.** The dylib is universal (arm64 + x86_64), built by `src-tauri/build.rs` or a build script. It ships with `np.pl` in the bundle resources, with paths resolved from the app's resource dir at runtime.
- **Volt rules for the widgets.**
  - Inter for text, Barlow Condensed for titles and numbers, accent `#C8F04A`.
  - Cards are drawn by the host; widget padding is 12 px through `.v-card`.
  - Text is at least 9 px, nothing overflows, long texts ellipsize, no uppercase labels.
  - Sizes: 115×104 for 1 column, 238×104 for 2 columns, 484×52 for the strip.
- **Locales** in id and en.
- **Process.** Commit only your files on `feat/paket-widget`. Never push, merge, stash, reset or switch branches.
- **Checks.** Run `npx tsc --noEmit`, `npm test`, `npm run build:modules` and `cargo test` (in `src-tauri`) before committing.

## Review Focus

1. **Helper dies or hangs.** The service restarts it with backoff. Widgets show the empty state, and no panel or UI freezes, because no blocking reads happen on the main thread.
2. **Package off, then on.** The helper stops and starts again. No orphaned perl process remains after app quit; check with `pgrep -f np.pl`.
3. **Nothing playing, or a source without artwork** (YouTube in a browser). The widgets show the empty state, or the gradient tile with the title's first word.
4. **Very long title or artist names.** They ellipsize in all three widgets.
5. **Controls.** The optimistic play/pause flip is corrected by the next read, and does not flicker back and forth.

### Task 1: The helper and `media_service`

**Files:**
- Create: `src-tauri/media/notching_media.m`, `src-tauri/media/np.pl`, and `src-tauri/src/media_service.rs`.
- Modify:
  - `src-tauri/build.rs` to build the universal dylib.
  - `src-tauri/tauri.conf.json` for the bundle resources.
  - `src-tauri/src/lib.rs` for wiring and app exit.
  - `src-tauri/src/modules/gate.rs` and `manifest.rs` for the new `Capability::Media` with methods `now` and `command`.
  - `src-tauri/src/module_commands.rs`: `module_gone`/`module_on` handling, and the call dispatch for `media`, wherever capability calls are routed. Follow how `timer` is routed.

**Interfaces:**
- **Helper stdout JSON** (one object per line):
  - `{"title":s|null,"artist":s|null,"album":s|null,"duration":f|null,"elapsed":f|null,"rate":f,"at":ms,"app":s|null,"art":"data:image/…;base64,…"|null}`
  - With nothing playing, all fields are null and `rate` is 0.
- **Helper stdin** takes one word per line: `toggle`, `play`, `pause`, `next` or `prev`.
- **`media.now`** returns the same shape as the helper line, plus `"on": bool`. `on` is false when the helper is not running or has said nothing yet.
- **`media.command`** takes one argument, one of the five words. It returns `{ "ok": true }`, or an error string.

**Steps:**
- [ ] **Step 1: Write failing Rust tests.**
  - JSON line parsing: a good line, a bad line skipped, and the nothing-playing line.
  - The backoff sequence: 1, 2, 4, 8, 16, 30, 30.
  - The gate: the `media` capability's `now`/`command` are authorized only when declared, and an unknown method is refused.
  - The command parsing whitelist.
- [ ] **Step 2: Write the helper.**
  - Use `MRMediaRemoteRegisterForNowPlayingNotifications`, observe `kMRMediaRemoteNowPlayingInfoDidChangeNotification` and the playing-state change, and `MRMediaRemoteGetNowPlayingInfo`/`MRMediaRemoteGetNowPlayingApplicationBundleIdentifier` where present (via dlsym; tolerate missing symbols).
  - Send commands with `MRMediaRemoteSendCommand` (0 play, 1 pause, 2 toggle, 4 next, 5 prev).
  - Run a CFRunLoop on the main thread and read stdin on a background thread. Exit on stdin EOF.
  - Downscale artwork with ImageIO/CoreGraphics.
  - The perl script loads the dylib with DynaLoader and calls its entry, as in the spike.
- [ ] **Step 3: Write `media_service`.**
  - Spawn with `std::process::Command`, keep stdin open, and read stdout lines on a thread.
  - Store the latest state behind a Mutex, restart with backoff, and stop on `module_gone("musik")` and at app exit.
- [ ] **Step 4: Build check.**
  - Run `cargo test` and `npx tauri build --bundles app`, both in the background, because the build takes minutes.
  - Then run the bundled helper by hand from the built .app resources, with media playing in Arc or Music. It must print a JSON line with a title.
  - Run `pgrep -f np.pl` after killing the app to prove nothing lingers.
- [ ] **Step 5: Commit.** `feat(core): Now Playing through the system perl, as the owner chose, and the media capability`

  - `widgets/{player,strip,mini}.ts` with tests.
  - `now.ts` for the shared state model with tests.
- Modify:
  - `modules/index.json` to add `musik`.
  - The settings editor samples: `src/settings/pages/widget-samples.ts` and tests, plus a sample CSS block in `src/settings/settings.css` like the other packages.
  - The browser bridge, so the preview has fake media: `src/bridge-browser.ts`, or a new `src/bridge-browser-media.ts` like the timer one.

**Interfaces:**
- **Consumes** `kit.call('media','now')` and `kit.call('media','command', word)` from Task 1.
- **`now.ts`:** `position(state, nowMs): number`, which is the elapsed time advanced by `rate × (nowMs − at)` and clamped to the duration; `isEmpty(state): boolean`; `firstWord(title): string`.

**Steps:**
- [ ] **Step 1: Tests first.**
  - `now.ts`: position advances while playing, freezes when paused, and clamps.
  - Each widget renders title, artist and times in id/en. It shows the empty state, and shows the gradient tile with the first word when there is no artwork.
  - The controls call the command; the optimistic toggle is reverted by the next read.
- [ ] **Step 2: Implement** to the pictures at app size, following existing Volt widgets: `modules/fokus/widgets/breath.ts` for rings, and `modules/sekitar/widgets/hourly.ts` for a strip.
- [ ] **Step 3: Editor samples and the browser-bridge fake.** Check the three widgets in the browser preview at real size, with nothing overflowing.
- [ ] **Step 4: Verify.** Run `npx tsc --noEmit`, `npm test` and `npm run build:modules`.
- [ ] **Step 5: Commit.** `feat(musik): the Musik, Musik strip and Musik kecil widgets`
