# Gaya Volt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle every notch-page widget and the widget-page panel to the owner's "Notching Volt" design. Data and behaviour stay the same.

**Architecture:**
- A new widget-only kit (`src/kit/volt.css` and `src/kit/volt.ts`) carries the fonts, colour tokens and small helpers. Each widget package imports it after `kit.css`.
- The host draws each slot as a black rounded card, makes the strip 52 px, and adds a page head (name, "n / N").
- Each package then rebuilds its widget views to match the reference pictures. It keeps the exported view functions that the settings editor samples call.

**Tech Stack:** Tauri 2, vanilla TS, vitest (jsdom), Vite, `@fontsource` fonts.

**Spec:** `docs/superpowers/specs/2026-11-02-gaya-volt-design.md`. Reference pictures are in `docs/superpowers/specs/volt/*.png`. Exact design sizes and tokens are in `docs/superpowers/specs/volt/tree.txt`.

## Global Constraints

**Sizes**
- Scale factor from design to app is k ≈ 0.62.
- Text size is the design size × 0.62, rounded, **never under 9 px**.
- Card radius 17 px. Card padding 12 px; 0 for Jam analog, Timer, Napas, Bulan.
- Strip 52 px high, 16 px under the row, with no dotted line.

**Colours**
- ink `#F3F5F0`, ink-2 `#C4C8BF`, muted `#8C9187`, dim `#80857B`, faint `#454941`, track `#23251F`.
- accent `#C8F04A`, accent-soft `#1D260B`, on-accent `#0F1404`.
- Card `#000`, with a ring of `0 0 0 1px #FFFFFF14`.
- **Accent only.** The old red (`--red`, `.rd`, `.now`) is not used in any notch-page widget.

**Fonts**
- Barlow Condensed (600/700) for big numbers and titles; Inter (500/600) for labels and small text.
- Both come from `@fontsource/*` packages, never from the network.
- Labels are not uppercased and get no wide letter-spacing.

**Scope**
- The Volt look applies only to widget iframes on notch pages, the page panel, and the settings editor's widget samples.
- Module pages, the Settings window chrome, the pill and the notice ears keep their look.
- Do not change `src/kit/kit.css` rules that the host or Settings use. `big()` and `small()` stay for `system-stat` and `cleaner`.

**Behaviour**
- No change to data, prefs, Rust, clicks, drags or full views, beyond spec §6.
- Each package keeps the exported view function names and argument types that `src/settings/pages/widget-samples.ts` and `widget-preview.ts` import.

**Text**
- Indonesian and English locales are both updated for any new or changed text.

**Fit**
- No element may overflow its frame at 109×104, 234×104 or 484×52.
- The longest realistic text must fit. Shrink it to no less than 9 px, then shorten the text.

**Process**
- Commit only the files you changed, on `feat/paket-widget`. Never push, merge, stash, reset or switch branches.
- Run `npx tsc --noEmit`, `npm test` and `npm run build:modules` before each commit. `cargo` is not needed; there are no Rust changes.

## Review Focus

1. **Longest texts at app size.** "Rabu, 31 Des" and "Minggu ke 53" in the 1-column date areas, "Maghrib" with "10 j 59 m lagi", "−11 jam · malam" in Zona waktu, and long reminder titles. Each must fit or ellipsize, never overflow.
2. **Strip at 52 px.** Weekstrip, hourly and timer strip must fill the new height. The settings editor's strip slot and picker card must also be 52 px.
3. **Fonts inside the sandboxed iframes.** `@fontsource` CSS must be bundled into each package's build (`dist-modules`), not loaded from the host.
4. **Timer tile while dragging.** The Volt ring view must keep the tests from `a4b084b`: drag while live, a poll during a drag, cancel.
5. **Page head without a notch.** On an external monitor the head row adds height. The panel size from `route.ts` must include it, so nothing is clipped.

### Task 1: Volt kit

**Files:**
- Modify: `package.json`, `package-lock.json` (add `@fontsource/inter`, `@fontsource/barlow-condensed`, both `^5.3.0`)
- Create: `src/kit/volt.css`, `src/kit/volt.ts`, `src/kit/volt.test.ts`

**Interfaces:**
- Produces:
  - `num(text: string, px: number, cls?: string): HTMLDivElement`. Returns `div.v-num` (plus `cls`) with `style.fontSize = px + 'px'` and the text.
  - `bar(frac: number, cls?: string): HTMLDivElement`. Returns `div.v-bar` with one child `span.v-fill`, whose `style.width` is the percentage clamped to 0–100, written like `"40%"`.
  - `segs(count: number, lit: number | number[], cls?: string): HTMLDivElement`. Returns `div.v-segs` with `count` `span.v-seg` children. A number `lit` marks segments `0..lit-1` with class `on`; an array marks those indices.
  - `lab(text: string, cls?: string): HTMLSpanElement`. Returns `span.v-lab`.
  - CSS classes:
    - `.v-card`: the widget root. Flex column, `box-sizing: border-box`, `height: 100vh`, `padding: 12px`. `.v-card.flush` has padding 0.
    - `.v-lab`: Inter 600 10px, muted.
    - `.v-lab.ink`: ink colour.
    - `.v-num`: Barlow Condensed 600, `line-height: 1`, ink.
    - `.v-acc`: accent colour.
    - `.v-bar` and `.v-fill`: a 2 px track with an accent fill and round ends.
    - `.v-segs`, `.v-seg` and `.v-seg.on`: 2 px high, 3 px gap, track and accent.
    - `.v-pill`: accent background, on-accent text, radius 999, Inter 600 9px, padding 2px 6px.
    - `.v-pill.soft`: accent-soft background, accent text.
  - CSS custom properties on `:root`: `--v-ink`, `--v-ink2`, `--v-muted`, `--v-dim`, `--v-faint`, `--v-track`, `--v-acc`, `--v-acc-soft`, `--v-on-acc`. Also `html, body { font-family: "Inter", -apple-system, sans-serif; color: var(--v-ink); }`.

- [ ] **Step 1: Write failing tests** in `src/kit/volt.test.ts`:
  - `bar(0.4)` has a fill width of `"40%"`. `bar(1.7)` gives `"100%"`, and `bar(-1)` gives `"0%"`.
  - `segs(5, 2)` has 5 children, and the first 2 have class `on`. `segs(5, [3])` has only index 3 `on`.
  - `num('09.41', 40)` has class `v-num`, text `09.41` and fontSize `40px`.
  - `lab('Jakarta', 'ink')` has class `v-lab ink`.
- [ ] **Step 2:** Run `npx vitest run src/kit/volt.test.ts`. Expected: FAIL (module missing).
- [ ] **Step 3:** Install the two font packages. Write `volt.ts` and `volt.css`. The `@import` lines for `@fontsource/inter/latin-500.css`, `latin-600.css` and `@fontsource/barlow-condensed/latin-500.css`, `latin-600.css`, `latin-700.css` go at the top of `volt.css`.
- [ ] **Step 4:** Run `npx vitest run src/kit/volt.test.ts`, then `npx tsc --noEmit`. Expected: PASS.
